# Ambiente das medicoes deste trabalho (29/08/2026).
#
# So o fecho de dependencias das tres bibliotecas que o projeto realmente usa:
#
#   pymupdf                extrai o texto do PDF               (rag/corpus.py)
#   sentence-transformers  o cross-encoder do reranker         (rag/recuperacao.py)
#   pytest                 os testes
#
# O restante da lista sao dependencias transitivas dessas tres. NAO ha aqui nenhuma
# biblioteca de busca, de RAG, de PLN ou gerador de analisador sintatico: o BM25, o
# lexico, a gramatica de intencoes e o analisador sao escritos a mao (ver rag/compilador
# e rag/recuperacao). Isso e verificavel com um grep dos imports.
#
# As versoes estao fixas de proposito: o piso de score de -3.2 do guardrail e calibrado
# contra os escores DESTE cross-encoder sob ESTAS versoes. Trocar sentence-transformers ou
# torch muda os escores e pode invalidar o 31/31 sem nenhum erro aparecer.
#
# Para reproduzir o ambiente exato:
#
#   pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
#   pip install -e . --no-deps
#
# ATENCAO ao torch: aqui vale o build **somente CPU** (torch.__version__ reporta "+cpu"),
# e o `pip freeze` nao registra esse sufixo. Instalar do PyPI puxa o build com CUDA, que
# nao e o que foi medido. Dai o --index-url acima.
#
